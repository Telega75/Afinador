# Afinador de punteiro

Afinador web para el punteiro de la gaita gallega. La página permite ver la afinación mientras se toca y analizar la grabación completa al terminar.

## Uso

Abre `index.html` en un navegador moderno. Para usar el micrófono, concede permiso y sirve la página desde HTTPS o localhost si el navegador lo requiere. También puedes cargar un archivo de audio.

La referencia inicial es A=440 Hz. La tonalidad y los objetivos de afinación natural se pueden ajustar desde **Ajustes**.

## Privacidad

El audio se procesa en el navegador. Este repositorio no incluye las muestras MP3 usadas durante el desarrollo.
